=== Parser, AST et Converter

Comprendre le cycle de vie d'un document Asciidoc :

* *Parser* : Analyse du texte source
* *AST* : Représentation arborescente
* *Converter* : Transformation vers le format cible

    subgraph PHASE2 [Phase 2 : Structuration - Cible : AST / Objets]
        PARSER --> AST{AST - Arbre du Document}:::core

        %% Extensions agissant sur l'AST
        AST --> BLK[BlockProcessor]:::extension
        AST --> BMACRO[BlockMacroProcessor]:::extension
        AST --> IMACRO[InlineMacroProcessor]:::extension

        %% Le TreeProcessor intervient quand l'AST est fini
        BLK & BMACRO & IMACRO --> TREE[TreeProcessor]:::extension
    end

    TREE --> CONV[Convertisseur Backend HTML5]:::core

    subgraph PHASE3 [Phase 3 : Post-Conversion - Cible : HTML / Sortie]
        CONV --> POST[Postprocessor]:::extension
        POST --> DINFO[DocinfoProcessor]:::extension
    end

    DINFO --> FINAL_HTML[Fichier Final .html]:::output
    FINAL_HTML --> END((Fin))

    %% Légende des cibles
    PHASE1 -.-> |Agit sur le Texte| ADOC_DOC
    PHASE2 -.-> |Manipule les Objets| AST
    PHASE3 -.-> |Modifie le Rendu| FINAL_HTML

==== DocinfoProcessor

Cas Particulier de Processor

Objectif: dédié à injecter du contenu dans le head ou en bas du body.

Utilisé par `asciidoctor-reveal.js` pour insérer le js de `reveal.js`, les styles custom etc...

[source,javascript]

module.exports = function ({node}) {
    const jNode = toJSON(node);
    return $blockWithTitle(
        {
            title: jNode.title,
            id: jNode.id,
            class: ['olist', jNode.style, jNode.role],
            ...data_attributes(node)
        },
        $(
            'ol',
            {
                class: jNode.style,
                start: jNode.attributes.start,
                type: jNode.marker,
                reversed: jNode.options.reversed,
            },
            ...jNode.items.map(item =>
                $(
                    'li',
                    {id: item.id, class: item.role},
                    $printItemContent(item)
                )
            )
        )
    )
}
