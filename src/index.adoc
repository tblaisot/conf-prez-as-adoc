=== Why not Markdown ?

Nombreuses "Flavors"

=== Markdown

Créé en *2004* par John Gruber… sans spécification stricte.

[%step]
* *CommonMark* : standardisation stricte, syntaxe minimale
* *GFM* : tables, checklists, code coloré _(GitHub)_
* *Pandoc* : LaTeX, citations, conversion multi-formats
* *MDX* : composants JSX/Vue injectés dans le contenu
* *Markdoc* : alternative déclarative sans JS arbitraire _(Stripe)_

=== J'aime pas Markdown

[%step]
*Résultat :* pas de « Markdown » universel.

[%step]
* Pas de parser unique → dépendance à la "flavor" choisie
* Pas d'AST exposé → impossible de contrôler "simplement" le rendu HTML

[NOTE.speaker]
John Gruber crée Markdown en 2004. Spec volontairement légère → trop ambiguë → explosion de variantes incompatibles entre elles.

=== Why Asciidoc ?

[%step]
Une séparation stricte entre :

[%step]
* Contenu structuré
* Mise en forme

===== BlockProcessor

.custom block
[source,asciidoc]
-----
[custom_block]
----
mon super block
----
-----

[source,javascript]
----
module.exports = function (registry) {
  registry.block(function () {
    const self = this;
    self.named('custom_block');
    self.onContext('paragraph');
    self.process(function (parent, reader) {
      const lines = reader.getLines().map(function (l) { return l.toUpperCase() })
      return self.createBlock(parent, 'paragraph', lines);
    });
  });
}
----

===== SLIM

[source,ruby]

- _has_title = title?
- content_for :ol
  ol id=(id unless _has_title) class=[(style unless style == 'arabic'), ('fit' if (_fit = option? :fit)), *build_roles, role] start=(local_attr :start) reversed=('true' if option? :reversed)
    - items.each do |_item|
      li class=('line' if _fit)
        span.primary=_item.text
        - if _item.blocks?
          =_item.content

    figcaption=title
    - yield_content :ol
- else

module.exports = function ({node}) {
    const jNode = toJSON(node);
    return $blockWithTitle(
        {
            title: jNode.title,
            id: jNode.id,
            class: ['olist', jNode.style, jNode.role],
            ...data_attributes(node)

            'ol',

                class: jNode.style,
                start: jNode.attributes.start,
                type: jNode.marker,
                reversed: jNode.options.reversed,
